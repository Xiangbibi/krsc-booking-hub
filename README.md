# KRSC Booking Hub – Prototype

Clickable prototype of the TO-BE booking process for **Kaeng Krachan Riverside Resort & Camping (KRSC)**.

## How to open
- **Online:** open the GitHub Pages link of this repository.
- **Offline:** download `index.html` and double-click it. No installation or internet connection is needed.

## Pages
| Page | Level | Shows |
|---|---|---|
| 1. Customer booking | Standard | Choose stay type, fill in once, choose only free houses, quotation and deposit |
| 2. Back office | Standard | Today, calendar, bookings, customer history, houses, D-7 → D-2 reconfirmation |
| 3. LINE chatbot | Premium (optional) | Answers common questions and drafts quotations for admin approval |
| 4. Team tasks | Standard | Daily tasks for kitchen, housekeeping, trainers and venue, with an "OK" reply |

## Data
House names, prices and activities come from the resort's public website (kaengkrachan.net). Customer and booking data are fictional examples. This is a prototype to show the TO-BE process, not a finished system.
